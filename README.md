# 👑 Real Sensi 👑 - Android Native Project

Proyecto oficial para compilar el APK de Real Sensi.
Incluye:
- Borde RGB como superposición (Overlay Service con FLAG_NOT_TOUCHABLE)
- Ventana flotante movible encima de Free Fire
- Optimizador Shizuku para RAM y caché sin root
- Lanzador de juegos directo por package name

## Compilación Fácil desde el Celular (Gratis):
1. Sube estos archivos a tu repositorio de GitHub desde tu teléfono.
2. Ve a la pestaña 'Actions' en GitHub.
3. El archivo '.github/workflows/build_apk.yml' compilará automáticamente tu APK instalable en 2 minutos.
4. Descarga el archivo 'app-debug.apk' e instálalo en tu Android.
